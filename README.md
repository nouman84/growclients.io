# growclients.io

One-page freelancer portfolio website for **Hebah Nouman** — freelance full-stack developer (web apps, AI automation, e-commerce, SEO).

## Stack

Pure static HTML/CSS/vanilla JS in a single `index.html`. No build step, no dependencies.

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Deployment

Deployed as a **free static site on Render** (see `render.yaml`). Pushes to `main` auto-deploy.

- Production URL: https://growclients.io (custom domain)
- Render URL: https://growclients-io.onrender.com
