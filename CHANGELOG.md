## [1.0.0] - 2026-06-12

### Added

- One-page freelancer website for Hebah Nouman: hero, services, skills, about, contact, footer.
- Skills section sourced from technologies used in production across all `~/development` projects.
- SEO meta tags, Open Graph tags, JSON-LD Person schema, inline SVG favicon.
- Responsive layout (mobile 375px → desktop), staggered load animations, scroll reveals, reduced-motion support.
- `render.yaml` for Render free static site deployment with security headers.
